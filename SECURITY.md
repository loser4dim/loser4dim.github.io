# Security Policy

## Supported Versions

Only the latest deployed version of this website is supported with security updates.

Previous versions and historical deployments are not actively maintained.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately using GitHub's [Private Vulnerability Reporting](https://github.com/loser4dim/loser4dim.github.io/security/advisories/new).

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential security impact
- Any relevant screenshots or proof-of-concept code

Please do not disclose security vulnerabilities through public GitHub Issues before they have been addressed.

Reports will be reviewed as availability permits. Confirmed vulnerabilities will be prioritized based on their severity and potential impact.

Thank you for helping keep this project secure.
